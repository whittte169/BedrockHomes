# BedrockHomes

BedrockHomes is a lightweight home points plugin for [Endstone](https://github.com/EndstoneMC/endstone) Minecraft Bedrock servers.

The plugin allows players to save named locations and teleport back to them later. Home points are stored locally in an SQLite database, including the player's name, coordinates, and dimension.

## Features

- Save named home points.
- Teleport to previously saved homes.
- Delete saved home points.
- Store home data in a local SQLite database.
- Keep track of the dimension in which each home was created.
- Provide an API for integration with other plugins.
